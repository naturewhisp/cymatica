# Note di ricerca R-M25-7 (2026-11-03)

Note di lavoro dei cinque filoni che alimentano il [dossier sul direttore musicale](../../M2_5_F5_Music_Director_Research.md). Sono materiale grezzo, non normativo: il riferimento è il dossier, che ne corregge alcuni punti.

| File | Filone |
|---|---|
| `architetture_gioco_musica.md` | Chi dirige gioco e musica, a quali scale di tempo |
| `coordinamento_ruoli.md` | Direttore contro agenti, generazione sequenziale o congiunta |
| `regole_insieme.md` | Regole d'insieme: metro, armonia, ruoli, registri, timbro |
| `sviluppo_autentico.md` | Sviluppo contro varietà fittizia, verifica con due ascoltatori |
| `ripetizione.md` | Ripetizione in ascolto isolato e in gioco |

**Da leggere con cautela:**

- ogni fonte riporta il proprio livello di verifica (FT, FT-parz, FT*, AM, SEC), e la maggior parte delle letture è parziale;
- i valori della riga B in `regole_insieme.md` («Tempi 1 e 3 = 1,00») sono un artefatto di calcolo, corretto nel dossier;
- altre incongruenze sono elencate nel dossier, paragrafo «Correzioni»;
- i percorsi locali citati nelle note si riferiscono a file temporanei non archiviati.

I testi estratti delle fonti non sono versionati.
